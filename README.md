# Домашнее задание №3. Обучение с учителем. Деревья решений и их ансамбли.

## Описание задания

На четвертой лекции мы познакомились с деревьями решений, бэггингом, случайным лесом и градиентным бустингом. В этом задании вам предстоит перенести пайплайны предобработки данных из предыдущих домашних заданий, собственноручно реализовать ансамблевые методы на основе деревьев решений и провести корректную серию вычислительных экспериментов.

Задание выполняется на двух наборах данных:

* **регрессия** — **NYC Taxi**;
* **бинарная классификация** — **IEEE-CIS Fraud Detection**.

---

## Постановка задачи

1. Сохранить и перенести пайплайны предобработки данных из предыдущего домашнего задания. Это можно сделать с помощью `joblib` ([пример](https://calmcode.io/course/scikit-save/introduction)) или [других инструментов](https://scikit-learn.org/stable/model_persistence.html).

2. Реализовать собственноручно в виде **sklearn-совместимых классов** следующие алгоритмы:
   * **BaggingRegressor** — бэггинг для задачи регрессии;
   * **BaggingClassifier** — бэггинг для задачи бинарной классификации;
   * **RandomForestRegressor** — случайный лес для задачи регрессии;
   * **RandomForestClassifier** — случайный лес для задачи бинарной классификации.

   В качестве базового алгоритма в ансамблях необходимо использовать **дерево решений произвольной глубины**.

3. Сравнить ваши собственноручные реализации ансамблевых алгоритмов с готовыми реализациями из `sklearn`.

4. Сравнить результаты бэггинга и случайного леса с результатами, полученными с помощью различных реализаций **градиентного бустинга**. Для этого необходимо обучить модели из:
   * `sklearn`;
   * `XGBoost`;
   * `LightGBM`;
   * `CatBoost`.

5. Провести **серию экспериментов**:
   * подобрать и зафиксировать наборы гиперпараметров;
   * для каждого эксперимента сохранять необходимые и информативные метрики качества;
   * свести результаты в электронную таблицу-отчёт;
   * написать интерпретацию полученных результатов.

6. С помощью **лучшей выбранной модели** для каждой задачи сформировать и сохранить в корне репозитория **таблицы с предсказаниями для `X_test`**:
   * для задачи **регрессии** — файл **`regression_submission.csv`**;
   * для задачи **классификации** — файл **`classification_submission.csv`**.

   Требования к файлам с предсказаниями:
   * для задачи **регрессии** необходимо получить файл с колонками `[row_id, fare_amount]` или иным идентификатором и названием таргета, соответствующими вашему датасету;
   * для задачи **классификации** необходимо получить файл с колонками `[TransactionID, isFraud]`, где `isFraud` — **предсказанная вероятность положительного класса**;
   * формат файлов должен соответствовать примеру `sample_submission.csv`, если он предоставлен в наборе данных.
